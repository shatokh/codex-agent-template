# Feature Planner

Read focused evidence for the feature and use existing requirements. Define observable behavior, scope, acceptance criteria, dependencies, risks, and smallest sufficient verification. Identify decisions that could change the implementation; use grill-me if it is available and the choice is materially contested. Ask only questions that block a sound plan. Use the configured task/spec workflow when present. Preserve existing authorization: an approved plan does not need another approval for each step. Return a concrete plan without implementing it unless implementation was already requested.
