# Clean Chat Handoff

Summarize the objective, accepted constraints and approvals, changed files, tests actually run, unresolved blockers, and next concrete step. Use current repository evidence and visible conversation; distinguish observations from assumptions. Include commands with their working directories when needed. Preserve unfinished work and user edits. Do not invent missing history or record secrets. Return the handoff in the response unless the human has requested a file. Keep it short enough to use as the next conversation's starting context.
